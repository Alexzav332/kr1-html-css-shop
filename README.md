# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина.

## Структура проекта

- `index.html` — главная страница (с блоком FAQ и модальным окном заказа);
- `catalog.html` — каталог товаров (с панелью фильтров);
- `category.html` — страница категорий товаров;
- `product.html` — карточка товара (с таблицей характеристик, блоком отзывов и похожими товарами);
- `order.html` — оформление заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт для модального окна и валидации формы;
- `images/` — изображения товаров (`tovar1.png` … `tovar9.png`);
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS (Flexbox, Grid, БЭМ, CSS-переменные);
- JavaScript (базовый уровень);
- Git;
- GitHub.

## Самостоятельные доработки

1. **Блок отзывов** на странице товара — реализован через `<article>` и БЭМ-блок `review`.
2. **Блок FAQ** на главной странице — реализован через нативные `<details>` и `<summary>` (работает без JavaScript).
3. **Изображения товаров** — вместо текстовых заглушек используются теги `<img>` с атрибутом `alt`, подключены файлы `tovar1.png` … `tovar9.png`.
4. **Дополнительная страница** — `category.html` с категориями товаров.
5. **Расширенный каталог** — 9 товаров с названиями, описаниями, ценами и изображениями.
6. **Фиксированная кнопка «Наверх»** — ссылка `to-top` с `position: fixed`, в виде круглой кнопки со стрелкой.
7. **Sticky-фильтр каталога** — панель фильтров закреплена при прокрутке через `position: sticky`.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- `aspect-ratio` и `object-fit` для аккуратной работы с изображениями;
- `position: sticky` для фильтра каталога;
- структурированный файл `css/style.css`;
- БЭМ-именование классов без глубокой вложенности селекторов.

## JavaScript

В `js/main.js` реализовано:

- открытие модального окна `order-dialog` по кнопке «Заказать»;
- подстановка выбранного товара в скрытое поле `#selected-product` через `data-product`;
- закрытие модального окна по кнопке, крестику и клику по фону;
- валидация формы заявки через `checkValidity()` и `aria-invalid`;
- показ сообщения об успешной отправке и сброс формы.
